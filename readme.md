# Ejercicio 2 - README

Este archivo describe cómo ejecutar el script `ej2.py`.

## Requisitos

Se requiere tener instalado Python 3 en el sistema. Para instalarlo, sigue los pasos según tu sistema operativo:

### En Ubuntu/Debian:
```bash
sudo apt update
sudo apt install python3
```

## Ejecución

Para ejecutar el archivo con la resolucion del ejercicio 2, utiliza el siguiente comando en la terminal:

```bash
cd greedy/
python3 ej2.py
```
